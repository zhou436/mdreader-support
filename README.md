# MD Reader Support

Support and privacy information for MD Reader on macOS 14 or newer.

- [Support website](https://zhou436.github.io/mdreader-support/)
- [Privacy policy](https://zhou436.github.io/mdreader-support/privacy.html)
- [Report a problem or ask a question](https://github.com/zhou436/mdreader-support/issues/new/choose)

Issues are public. Remove private document text, personal information and sensitive screenshots before posting. A GitHub account is needed to submit an issue.

This repository contains public documentation only.
