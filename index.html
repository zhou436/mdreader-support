MD Reader Support

For macOS 14 and later · English app interface

Open Markdown files in tabs. Switch to Edit for source and live preview. The Help menu in the app includes the user guide, privacy policy and acknowledgements.

Common questions

How do I open files or make MD Reader the default?

Use File > Open, drag Markdown files into the window, or choose MD Reader from Finder’s Open With menu. To set it as the default, select a Markdown file in Finder, open Get Info, choose MD Reader under Open With, then select Change All.

How do I edit and navigate the preview?

Choose Edit to show the source on the left and preview on the right. In Edit mode, double-click a preview block or source line to locate the corresponding position. Drag the divider to resize the panes, or double-click it to reset their proportions.

Why are local images missing?

Choose Allow local images and grant the document’s folder or repository root. Image paths must remain inside the selected folder. PNG, JPEG, GIF, WebP and AVIF are supported up to 10 MB per image. Folder access lasts for the open document session.

Can I disable remote images?

Turn off View > Load Remote Images. This affects future rendering and requests; requests already sent cannot be recalled.

What if the document changed elsewhere?

Save asks before replacing external changes. Use Save As to keep a separate copy. Hard-linked documents require Save As.

How does recovery work?

After an interrupted session, choose Recover to inspect unsaved local copies, Later to retain them for another launch, or Discard Copies to remove them. Recovery does not overwrite original documents.

Get support

Report a problem, ask a question, or suggest an improvement through the support tracker. Include the app version, macOS version, steps, expected result and actual result.

Reports are public. Remove private document content, personal information and sensitive screenshots before posting. A GitHub account is needed to submit a report.
